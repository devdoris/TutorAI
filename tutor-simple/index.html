Divide the board: { "do": "layout", "grid": "2x2", "panels": ["…"] }, then give objects "panel": "tl". Bring one forward: { "do": "focus", "at": ["id"] }. Change scene: { "do": "transition", "kind": "wipe" | "fade" | "sweep" }.
Icons from the internet: "icon": "simple-icons:whatsapp" (any collection on icon-sets.iconify.design). An object with "explain": [...] comes forward when tapped. Try examples/divided-board.json.
